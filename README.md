# 城建设计局 · 局内 v3.3 Demo

在线试玩：https://fuhao-dev.github.io/city-builder-demo/

> 30 回合城市经营 / 任务 / 满意度 / 劳力占用的 H5 原型。纯 HTML + CSS + 原生 JS，无构建、无 CDN。

## 打开

直接双击 `index.html`，不需要构建、不需要服务器、不依赖 CDN；也可以直接访问上面的 GitHub Pages 地址。

- URL 加 `?seed=123` 可以固定随机种子（蓝图、任务刷新）。
- 本机最佳最终声望存在 `localStorage`，键名 `dsh_city_best_rep_v33`。

## 一局怎么玩

30 回合，每回合 1 次建造。目标：累计声望。

1. **选开局蓝图**：开局 3 选 1；之后声望到 10 / 25 / 45 / 65 各再 3 选 1。
2. **补基础供给**：农场、水厂、原料站、电站各 1 劳力；前 4 座共 250 金。
3. **注意劳力**：人口常驻被建筑占用；P5 建完 4 座基础只剩 1 劳力，2 劳力的服装厂建不了。做 +1 人口任务，或**停用一座基础**腾劳力（停用后该基础不再供给）。
4. **做任务**：任务栏不限张数；任务占用资源、给人口/永久供给/声望/金钱。普通任务也给声望（+3~+6），限时/恶性更高。
5. **结束回合**：结算满意度。`<0` 掉人口，`0–10` 稳定，`>10` 给声望；人口惩罚分段递增，人越多每多 1 人越贵。
6. **劳力不足不能进下回合**：如果人口掉到已占用以下，必须先停用建筑，按钮才会解锁。

## 界面

- 左列：8 资源（上回合结算）+ 城市建筑（按类型分组，用 − / + 设置启用数量）。
- 中列：任务栏（接取，显示“接后 sat”）+ 进行中（进度/放弃）。
- 右列：建造（基础 + 已解锁蓝图）+ 日志。
- 底栏：进入下回合、新游戏；提示当前是否还能建造、种子。

## 文件

- `index.html` / `style.css` / `ui.js`：界面。
- `game.js`：纯逻辑，无 DOM，Node 可直接 `require`。
- `test_game.js`：114 条断言，含起手、四基础、劳力门槛、按类型设置启用数量、任务、限时、恶性 A/B、蓝图节点、30 回合自动跑。
- `test_balance.js`：简单贪心 AI 的 5 个种子结果。
- `DESIGN.md`：v3.3 局内规则全文（数值、任务表、蓝图、边界情况）。

```bash
node test_game.js
node test_balance.js
```
