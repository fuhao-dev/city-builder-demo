# 城建设计局 · 建设关卡 v3.12.0 Demo

在线试玩：https://fuhao-dev.github.io/city-builder-demo/

## 打开

直接双击 `index.html`，不需要构建、不需要服务器、不依赖 CDN。

主要版本更新见 [CHANGELOG.md](CHANGELOG.md)。

- **自动存档**：每次操作后写入 `localStorage`（键名 `dsh_city_save_v34`）；刷新页面会自动恢复上次进度，不需要手动保存。
- URL 加 `?seed=123` 打开固定种子的选关；`?seed=123&level=agriculture&difficulty=hard&buff=food_aid` 打开指定关卡的配置页，点击“开始本局”才替换当前存档。关卡 ID 为 `town` / `agriculture` / `education` / `industry` / `health` / `metropolis`。
- 本机最佳最终声望存在 `localStorage`，键名 `dsh_city_best_rep_v33`；刷新不会丢。
- 本机通关记录和最佳通关声望按“关卡 × 难度 × BUFF”保存在 `dsh_city_campaign_v2`；旧 `v1` 成绩只迁入普通＋无加成，原记录保留。没有关卡字段的旧存档恢复为自由经营，不追认通关；没有开局配置的存档按普通＋无加成恢复，不重复发放开局奖励。

## 开局配置

流程为“选择关卡 → 选择难度与 BUFF → 确认开局 → 选择蓝图”。开局前展示金钱、基础供给和人口需求明细；取消选择可返回原城市。配置在本局内固定，刷新会随存档恢复。首版全部开放，每局最多一个 BUFF，也可不选；声望解锁成长后续再做。

| 难度 | 效果 |
|---|---|
| 普通 `normal` | 标准人口需求 |
| 困难 `hard` | 八项人口需求 ×1.15 |

| BUFF | 效果 |
|---|---|
| 无加成 `none` | 标准开局 |
| 建设筹备 `preparation` | 初始金钱 +60（300 → 360），只发一次 |
| 粮食援助 `food_aid` | 基础食物供给每回合 +2（3 → 5），不是库存 |
| 节水设施 `water_saving` | 人口用水需求 ×0.9 |

`人均需求 = 基础人均需求 × 难度倍率 × BUFF 倍率`，保留精度，人口总需求汇总后统一保留两位小数。困难＋节水的人均用水为 `0.5 × 1.15 × 0.9 = 0.5175`；P9 的人口用水为 4.66，不能先把人均值舍入为 0.52。建筑额外消耗和任务占用不乘人口倍率。资源卡、任务余额、高级减产、预测、建筑净产出和目标验收采用同一配置。

## 建设目标

六关均可直接选择，每局 30 回合。**在 T30 完成奖励、建设和任务操作后，点击“验收本关”，全部条件同时符合才通关**。提前达标不会锁定；未通关也保留声望成绩。

| 关卡 | 人口 | 资源净余量 | 满意度 |
|---|---:|---:|---:|
| 安居小镇 | ≥9 | — | ≥20 |
| 农业基地 | ≥15 | 食物 ≥18 | ≥35 |
| 学府之城 | ≥12 | 教育 ≥4 | ≥50 |
| 工业重镇 | ≥15 | 原料 ≥12、电力 ≥12 | ≥50 |
| 康养之城 | ≥12 | 药品 ≥4 | ≥65 |
| 繁荣都会 | ≥20 | 食物、原料、电力、水分别 ≥0 | ≥65 |

`资源净余量 = 实际供给 − 城市需求（人口及建筑消耗）− 全部任务占用`，计入仓库减免、高级减产与启停建筑。顶部目标面板显示当前进度和差距，建造预览同时展示建成后的目标值。最终验收只读取当前城市，不会再结算一次声望或人口。

后 3 关分别侧重产业配套、民生品质与综合扩张：工业关需要同时投资原料和电力；康养关需要补齐制药投入、调配劳力并兼顾其他民生；都会关要在扩大人口后维持生活品质，四项基础资源分别验收，某项富余不能抵消另一项缺口。

## 一局怎么玩

先选择建设关卡、难度和 BUFF；每回合 1 次建造或城镇升级。建设目标决定通关，累计声望记录经营成绩。

1. **选开局蓝图**：开局 3 选 1。之后声望**不再**给蓝图；蓝图改由城镇升级获得。
2. **补基础供给**：农场、水厂、原料站、电站各 1 劳力；前 4 座共 252 金。普通＋无加成时，基础生产建筑满产净产出为 **-0.5**，同资源蓝图 **+1.5**；困难和节水会改变这个比较值。
3. **看净产出，而不是只看产量**：1 劳力占用 1 人，`净产出 = 产出总和 − 额外消耗总和 − 劳力 × 本局八项人均需求合计`。普通＋无加成合计 6.5，困难＋无加成 7.475，普通＋节水 6.45，困难＋节水 7.4175。建造卡和预览会直接显示配置后的净产出；实际供需仍分别计算，不会重复扣。
4. **升级城镇**：当前人口达到 P6 / P9 / P12 / P15 时，建造面板会出现“升级城镇”按钮。升级消耗当回合建造行动，不花金钱、不占 24 座建筑上限、不占劳力；每级弹出 **5 选 2** 蓝图。人口掉到门槛以下不会降级，但也不能继续升下一级；T30 不能升级。
5. **注意人口与高级减产**：所有建筑最多占 1 人口；市场、仓库等部分蓝图是 0 人口。衣服/家具/药品/教育建筑需要基础资源：食物、原料、电力、水每缺 1 项，高级产出 -25%，最多 -100%（四项全缺停产）；部分减产仍按原高级投入计算，停产时才暂停额外基础消耗。**服装合作社的原料、药草园的食物等混合基础产出会计入低阶检查**，不会出现原料卡足够却仍误减产。
6. **混合蓝图**：水培农场、地热电站、回收工坊、药草园、服装合作社、医教中心用 1 劳力/1 槽同时提供两种资源；适合补第二缺口或省人口。蓝图池共 **16 张**，一局最多拿 9 张。
7. **做任务**：任务栏不限张数；任务占用资源、给金钱/声望。普通任务声望 +3~+6，限时/恶性更高。接取前看“接取后预计满意度”“变化”“接取后预计完成回合”和“下回合声望 +N”；预计完成会计入接取后新增占用造成的超额减速，超过 T30 会提前标红。**每种占用资源当前供给必须大于其他任务占用，0 产出资源不能接**，仓库减免按同一口径计算。任务所用资源超额合计为 0 时正常推进；`0 < 超额 < 2` 为 0.8 速，`2 ≤ 超额 < 3` 为 0.6 速，`超额 ≥ 3` 为 0.5 速。
8. **任务奖励二选一**：完成后弹出奖励选择，**金钱+人口** 或 **金钱+资源永久供给**（声望共通）。人口选项含固定 +2 加成；资源选项直接增加永久供给，不占建筑/劳力。未选择前不能建造、升级、接取/放弃任务或进入下一回合；多个任务同时完成会排队逐个选择。
9. **建造前先看预览**：点击建筑卡打开预览，确认后才扣钱/占劳力；预览列出资源供需变化、净产出、满意度变化和具体高级减产原因（哪项低阶资源、可用/需求/缺口）。
10. **结束回合**：结算满意度。`<0` 掉人口；`0≤满意度<20` 不加声望；达到 **20 / 35 / 50 / 65 / 75** 时，每回合分别 **+1 / +2 / +3 / +4 / +5**。再按结算时当前人口封顶：**P<12 最多 +3，P12–14 最多 +4，P≥15 最多 +5**；城镇等级不保留上限，任务固定声望不受此上限影响。人口惩罚按人数分段累加：1–5 人每人 1，6–15 人每人 0.5，16–25 人每人 1，26 人起每人 1.5。每项资源满分 **15**，赤字 13、T30 回合压力 −5，起手满意度仍为 **9**。
11. **劳力不足不能进下回合**：如果人口掉到已占用以下，必须先停用建筑，按钮才会解锁。
12. **终局**：第 30 回合按钮变成“验收本关”（旧存档为“结算本局”）；T30 建造、领奖、启停与接取/放弃任务仍会改变验收值。终局显示通关结果、逐项目标差距、累计声望、城镇等级、人口、建筑数、任务完成数和剩余金钱。

## 界面

- 顶部：本关建设目标、当前值、门槛和差距；HUD 满意度随当前操作实时更新。
- 左列：8 资源卡显示“当前 → 下回合预测”；醒目大字“额外供给 / 缺口”（提供 − 占用 − 需求）；彩条总长度 = 需求 + 占用（金色占用、青/蓝已覆盖需求、红色斜纹供给缺口），满足分改为文字；高级减产时标“低阶不足·产出 N%”。满意度公式会红色标出“回合压力 N”；城市建筑按类型分组，用 − / + 设置启用数量。
- 中列：任务栏（接取，显示“接取后预计满意度”、变化、预计完成回合和减速原因；占用行按资源标出“余 X / 缺 X”，口径为**接取后供给 − 城市需求（人口及建筑消耗）− 接取后全部任务占用**；同时计入仓库减免、恶性 A→B 替换和高级减产；产出不足的任务置灰）+ 进行中（显示当前余额，自身占用只算一次，以及进度/完成奖励/放弃）；完成时弹出奖励二选一弹窗；预计完不成的任务标红。余额为负只提示城市缺口，不额外收紧接取门槛。奖励与蓝图选择弹窗均可“隐藏窗口，查看资源与人口”，右下角“返回选择”恢复。
- 右列：城镇升级卡 + 建造（基础 + 已解锁蓝图；点击建筑卡先看建造预览，确认后才建造）+ 日志。
- 底栏：进入下回合 / 验收本关、选关、规则、自动存档状态；提示剩余回合、是否还能建造/升级、种子。打开选关或配置页可返回当前城市，只有点击“开始本局”才替换进度。
- 配置与成绩：标题及终局显示难度和 BUFF；选关卡展示已通关配置数量，配置页展示该组合的最佳通关声望。HUD 的本机最高声望仍统计全部配置。
- HUD：回合、金钱、人口、满意度、声望、劳力、城市、**城镇等级 / 下阶人口**、最佳声望；满意度公式旁显示预测结算人口及对应每回合声望上限。

- `test_game.js`：502 条断言，含起手八项满足分 27 / 满意度 9、建筑人口上限（全部 ≤1、蓝图有 0 人口）、**净产出基准（基础 -0.5、蓝图 +1.5、占用 6.5）**、四基础、6 张混合蓝图、城镇 4 级门槛/行动消耗/不降级/T30/5 选 2 原子选择、声望不再给蓝图、停用/启用、按类型设置启用数量、任务产出门槛、仓库下零产出拒接、小数超额减速边界、计入城市需求的任务资源预览、限时、恶性 A/B、存档/预测、人口惩罚分段边界、新声望档位与人口上限、掉人口/人口奖励后的预测及实际到账、任务固定声望不受上限、回合压力、高级按项减产、混合建筑基础产出不误减产、建造预览、任务奖励二选一/队列阻塞、接取前完成回合估算与奖励队列不误报、刷新数量、30 回合自动跑。
- `test_balance.js`：简单贪心 AI 的 5 个种子结果；会接取所有可接任务、升级城镇并建造已解锁蓝图，当前 **18–23 座建筑**、**9 张蓝图**、城镇 Lv.4、最终声望 **37–69**。该脚本用于观察数值，不代表最优策略。
- `test_scenarios.js`：202 条关卡断言，覆盖六关门槛、多资源独立验收、同时达标、提前达标后失守、T30 建造/领奖/任务操作、仓库和高级减产、预测无副作用、重复验收、旧存档兼容与非法关卡；六条完整策略通过公开行动 API 重放。
- `test_run_config.js`：240 条断言，覆盖全部 8 种配置、精度、预测与结算一致、建筑投入不受倍率影响、粮食持续供给、旧存档不补发、非法配置不改变城市，以及分配置成绩和迁移。三组测试合计 **944 条断言**。
- `simulate_scenarios.js`：可复现的目标策略模拟，含常规/仅基础建筑两种路线、独立目标复核、存档往返与合法行动记录。后 3 关以新种子 40001–40100 验证 600 局：工业、康养两种路线均 100/100；都会常规 100/100、仅基础建筑 90/100。自动策略结果不代表真人通关率或最优解。
- v3.12.0 配置矩阵：固定既有策略，以种子 50001–50010 验证六关 × 两难度 × 四种 BUFF，共 480 局，477 局通关；普通 240/240，困难 237/240。三次失败均为教育净余量 3.90 未到 4，其中两次改用 `focused` 策略后通过。不把策略失败解释为种子无解。另重放 v3.11.0 的六关 × 三种子，普通＋无加成的供需、城市状态与结算逐项一致。

```bash
node test_game.js
node test_scenarios.js
node test_run_config.js
node test_balance.js
node simulate_scenarios.js --seeds=100 --start=40001 --levels=industry,health,metropolis
node simulate_scenarios.js --seeds=10 --start=50001 --matrix=1 --mode=all
node simulate_scenarios.js --seeds=10 --levels=education --difficulty=hard --buff=water_saving --mode=all
```

`--mode=all` 只跑可使用全部建筑的常规路线，`--mode=basic` 只跑基础建筑；不传 `--mode` 时两条路线都跑。`--matrix=1` 遍历全部开局配置。
