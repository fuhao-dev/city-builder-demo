## 打开

直接双击 `index.html`，不需要构建、不需要服务器、不依赖 CDN。

主要版本更新见 [CHANGELOG.md](CHANGELOG.md)。

## 一局怎么玩

30 回合，每回合 1 次建造或城镇升级。目标：累计声望；**最终得分只看累计声望**。

1. **选开局蓝图**：开局 3 选 1。之后声望**不再**给蓝图；蓝图改由城镇升级获得。
2. **补基础供给**：农场、水厂、原料站、电站各 1 劳力；前 4 座共 252 金。基础生产建筑净产出统一为 **-0.5**，同资源蓝图统一 **+1.5**（四项高阶资源人均需求改为各 1 后，1 人占用成本为 6.5）。
3. **看净产出，而不是只看产量**：1 劳力占用 1 人，其八项需求合计 **6.5**（食物 1、原料/电/水各 0.5、四项高阶各 1），作为建筑的负向产出；`净产出 = 产出总和 − 额外消耗总和 − 劳力 × 6.5`。建造卡和预览会直接显示净产出。它是定值/比较口径，实际供需仍按产出与人口需求分别计算，不会重复扣。
4. **升级城镇**：当前人口达到 P6 / P9 / P12 / P15 时，建造面板会出现“升级城镇”按钮。升级消耗当回合建造行动，不花金钱、不占 24 座建筑上限、不占劳力；每级弹出 **5 选 2** 蓝图。人口掉到门槛以下不会降级，但也不能继续升下一级；T30 不能升级。
5. **注意人口与高级减产**：所有建筑最多占 1 人口；市场、仓库等部分蓝图是 0 人口。衣服/家具/药品/教育建筑需要基础资源：食物、原料、电力、水每缺 1 项，高级产出 -25%，最多 -100%（四项全缺停产）；部分减产仍按原高级投入计算，停产时才暂停额外基础消耗。**服装合作社的原料、药草园的食物等混合基础产出会计入低阶检查**，不会出现原料卡足够却仍误减产。
6. **混合蓝图**：水培农场、地热电站、回收工坊、药草园、服装合作社、医教中心用 1 劳力/1 槽同时提供两种资源；适合补第二缺口或省人口。蓝图池共 **16 张**，一局最多拿 9 张。
7. **做任务**：任务栏不限张数；任务占用资源、给金钱/声望。普通任务声望 +3~+6，限时/恶性更高。接取前看“接取后预计满意度”“变化”“接取后预计完成回合”和“下回合声望 +N”；预计完成会计入接取后新增占用造成的超额减速，超过 T30 会提前标红。**每种占用资源当前供给必须大于已占用，0 产出资源不能接**。同一资源超额时，相关任务进度变慢（超 1 为 0.8 速、超 2 为 0.6 速、超 3+ 为 0.5 速）。
8. **任务奖励二选一**：完成后弹出奖励选择，**金钱+人口** 或 **金钱+资源永久供给**（声望共通）。人口选项含固定 +2 加成；资源选项直接增加永久供给，不占建筑/劳力。未选择前不能建造、升级、接取/放弃任务或进入下一回合；多个任务同时完成会排队逐个选择。
9. **建造前先看预览**：点击建筑卡打开预览，确认后才扣钱/占劳力；预览列出资源供需变化、净产出、满意度变化和具体高级减产原因（哪项低阶资源、可用/需求/缺口）。
10. **结束回合**：结算满意度。`<0` 掉人口；`0–19.9` 稳定、不加声望；`20–29.9` 每回合 +1，`30–39.9` +2，`40–49.9` +3，`50–59.9` +4，`≥60` +5（最高 5）。每项资源满意度满分 **15**，八项合计 0–120；赤字仍为 13、人口惩罚仍为原表、回合压力仍为 T30 −5，因此起手是 **9** 而不是 0，整体更宽松。
11. **劳力不足不能进下回合**：如果人口掉到已占用以下，必须先停用建筑，按钮才会解锁。
12. **终局**：第 30 回合按钮变成“结算本局”；终局面板显示累计声望、城镇等级、人口、建筑数、任务完成数和剩余金钱。

## 界面

- 左列：8 资源卡显示“当前 → 下回合预测”；彩条总长度 = 需求 + 占用（金色占用、青/蓝已覆盖需求、红色斜纹供给缺口），满足分改为文字；高级减产时标“低阶不足·产出 N%”。满意度公式会红色标出“回合压力 N”；城市建筑按类型分组，用 − / + 设置启用数量。
- 中列：任务栏（接取，显示“接取后预计满意度”、变化、预计完成回合和减速原因；产出不足的任务置灰）+ 进行中（进度/占用/完成奖励/放弃）；完成时弹出奖励二选一弹窗；预计完不成的任务标红。
- 右列：城镇升级卡 + 建造（基础 + 已解锁蓝图；点击建筑卡先看建造预览，确认后才建造）+ 日志。
- 底栏：进入下回合 / 结算本局、新游戏、规则、自动存档状态；提示剩余回合、是否还能建造/升级、种子。
- HUD：回合、金钱、人口、满意度、声望、劳力、城市、**城镇等级 / 下阶人口**、最佳声望。

## 文件

- `index.html` / `style.css` / `ui.js`：界面。
- `game.js`：纯逻辑，无 DOM，Node 可直接 `require`；含 `exportState / importState / forecast / forecastTask / buildPreview / estimateTaskFinish / townUpgradeStatus / upgradeTown / chooseBlueprints / chooseReward / buildingNet`。
- `test_game.js`：369 条断言，含起手 27 分、建筑人口上限（全部 ≤1、蓝图有 0 人口）、**净产出基准（基础 -0.5、蓝图 +1.5、占用 6.5）**、四基础、6 张混合蓝图、城镇 4 级门槛/行动消耗/不降级/T30/5 选 2 原子选择、声望不再给蓝图、停用/启用、按类型设置启用数量、任务产出门槛、限时、恶性 A/B、存档/预测、15 分制声望档位、回合压力、超额减速、高级按项减产、混合建筑基础产出不误减产、建造预览、任务奖励二选一/队列阻塞、接取前完成回合估算与奖励队列不误报、刷新数量、30 回合自动跑。
- `test_balance.js`：简单贪心 AI 的 5 个种子结果；会接取所有可接任务、升级城镇并建造已解锁蓝图，当前约 **15–21 座建筑**、**7–9 张蓝图**、城镇 Lv.3–4、最终声望 **34–42**。

```bash
node test_game.js
node test_balance.js
```
