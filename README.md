# 城建设计局 · 局内 v3.5.0 Demo

在线试玩：https://fuhao-dev.github.io/city-builder-demo/

## 打开

直接双击 `index.html`，不需要构建、不需要服务器、不依赖 CDN。

- **自动存档**：每次操作后写入 `localStorage`（键名 `dsh_city_save_v34`）；刷新页面会自动恢复上次进度，不需要手动保存。
- URL 加 `?seed=123` 可以固定随机种子并强制开新局（会覆盖当前存档）。
- 本机最佳最终声望存在 `localStorage`，键名 `dsh_city_best_rep_v33`；刷新不会丢。

## 一局怎么玩

30 回合，每回合 1 次建造。目标：累计声望；**最终得分只看累计声望**。

1. **选开局蓝图**：开局 3 选 1；之后声望到 10 / 25 / 45 / 65 各再 3 选 1。开局 5 张任务，之后 T6 / T11 / T16 / T21 / T26 各追加 3 张。
2. **补基础供给**：农场、水厂、原料站、电站各 1 劳力；前 4 座共 250 金。
3. **注意人口与高级停产**：所有建筑最多占 1 人口；市场、仓库等部分蓝图是 0 人口。衣服/家具/药品/教育建筑需要基础资源，食物、原料、电力、水任一不足时全部高级建筑停产（额外基础消耗也暂停）。P5 建完 4 座基础仍可用 1 人口建服装厂，前期更常被金钱/供给卡住；人口掉到已占用以下时才需要停用建筑。
4. **做任务**：任务栏不限张数；任务占用资源、给人口/永久供给/声望/金钱。普通任务也给声望（+3~+6），限时/恶性更高。接取前看“接取后预计满意度”“变化”和“下回合声望 +N”；**每种占用资源当前供给必须大于已占用，0 产出资源不能接**。同一资源超额时，相关任务进度变慢（超 1 为 0.8 速、超 2 为 0.6 速、超 3+ 为 0.5 速）。
5. **结束回合**：结算满意度。`<0` 掉人口；`0–19.9` 稳定、不加声望；`20–29.9` 每回合 +1，`30–39.9` +2，`40–49.9` +3，`50–59.9` +4，`≥60` +5（最高 5）。人口惩罚分段递增，人越多每多 1 人越贵。**回合压力**：T1–6 为 0，T7 起线性增加到 T30 的 −5，基础满意度为正也扣，后期拿声望更难。
6. **劳力不足不能进下回合**：如果人口掉到已占用以下，必须先停用建筑，按钮才会解锁。
7. **终局**：第 30 回合按钮变成“结算本局”；接取预计超过 T30 才能完成的任务会标红提醒。

## 界面

- 左列：8 资源卡显示“当前 → 下回合预测”；彩条改为“占用 / 供给”状态（金色占用、青/蓝剩余），满足分改为文字；高级资源停产时标红。满意度公式会红色标出“回合压力 N”；城市建筑按类型分组，用 − / + 设置启用数量。
- 中列：任务栏（接取，显示“接取后预计满意度”和变化量；产出不足的任务置灰并显示原因）+ 进行中（进度/放弃）；预计完不成的任务标红。
- 右列：建造（基础 + 已解锁蓝图，蓝图卡显示省劳力/省槽说明）+ 日志。
- 底栏：进入下回合 / 结算本局、新游戏、规则、自动存档状态；提示剩余回合、是否还能建造、种子。

## 文件

- `index.html` / `style.css` / `ui.js`：界面。
- `game.js`：纯逻辑，无 DOM，Node 可直接 `require`；含 `exportState / importState / forecast / forecastTask`。
- `test_game.js`：200 条断言，含起手、建筑人口上限（全部 ≤1、蓝图有 0 人口）、四基础、停用/启用、按类型设置启用数量、任务产出门槛、限时、恶性 A/B、蓝图节点、存档/预测、声望档位、回合压力、超额减速、高级停产、刷新数量、30 回合自动跑。
- `test_balance.js`：简单贪心 AI 的 5 个种子结果；会接取所有可接任务，当前约 **18–24 座建筑**。

```bash
node test_game.js
node test_balance.js
```
