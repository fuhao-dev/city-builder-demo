# 城建设计局 · 局内 v3.4 Demo

在线试玩：https://fuhao-dev.github.io/city-builder-demo/

> 30 回合城市经营 / 任务 / 满意度 / 劳力占用的 H5 原型。纯 HTML + CSS + 原生 JS，无构建、无 CDN。

## 打开

直接双击 `index.html`，不需要构建、不需要服务器、不依赖 CDN；也可以直接访问上面的 GitHub Pages 地址。

- **自动存档**：每次操作后写入 `localStorage`（键名 `dsh_city_save_v34`）；刷新页面会自动恢复上次进度，不需要手动保存。
- URL 加 `?seed=123` 可以固定随机种子并强制开新局（会覆盖当前存档）。
- 本机最佳最终声望存在 `localStorage`，键名 `dsh_city_best_rep_v33`；刷新不会丢。

## 一局怎么玩

30 回合，每回合 1 次建造。目标：累计声望；**最终得分只看累计声望**。

1. **选开局蓝图**：开局 3 选 1；之后声望到 10 / 25 / 45 / 65 各再 3 选 1。开局弹窗顶部有目标/满意度/劳力/任务速览。
2. **补基础供给**：农场、水厂、原料站、电站各 1 劳力；前 4 座共 250 金。
3. **注意劳力**：人口常驻被建筑占用；P5 建完 4 座基础只剩 1 劳力，2 劳力的服装厂建不了。做 +1 人口任务，或**把一座基础的数量减到 0** 腾劳力（该基础不再供给）。
4. **做任务**：任务栏不限张数；任务占用资源、给人口/永久供给/声望/金钱。普通任务也给声望（+3~+6），限时/恶性更高。接取前看“接取后预计满意度”和变化量。
5. **结束回合**：结算满意度。`<0` 掉人口，`0–10` 稳定，`>10` 给声望；人口惩罚分段递增，人越多每多 1 人越贵。
6. **劳力不足不能进下回合**：如果人口掉到已占用以下，必须先停用建筑，按钮才会解锁。
7. **终局**：第 30 回合按钮变成“结算本局”；接取预计超过 T30 才能完成的任务会标红提醒。

## 界面

- 左列：8 资源卡显示“上回合 → 下回合预测”（供给 + 满足分）；城市建筑按类型分组，用 − / + 设置启用数量。
- 中列：任务栏（接取，显示“接取后预计满意度”和变化量）+ 进行中（进度/放弃）；预计完不成的任务标红。
- 右列：建造（基础 + 已解锁蓝图，蓝图卡显示省劳力/省槽说明）+ 日志。
- 底栏：进入下回合 / 结算本局、新游戏、规则、自动存档状态；提示剩余回合、是否还能建造、种子。

## 文件

- `index.html` / `style.css` / `ui.js`：界面。
- `game.js`：纯逻辑，无 DOM，Node 可直接 `require`；含 `exportState / importState / forecast / forecastTask`。
- `test_game.js`：137 条断言，含起手、四基础、劳力门槛、按类型设置启用数量、任务、限时、恶性 A/B、蓝图节点、存档/预测、30 回合自动跑。
- `test_balance.js`：简单贪心 AI 的 5 个种子结果。
- `DESIGN.md`：v3.4 局内规则全文（数值、任务表、蓝图、边界情况）。

```bash
node test_game.js
node test_balance.js
```

规则全文见 `DESIGN.md`（v3.4）。
